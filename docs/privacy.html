Kebijakan Privasi

Berlaku sejak 26 September 2026

SheetEngine Enterprise adalah aplikasi desktop untuk mengolah berkas tabular dan sumber basis data. Data yang Anda buka diproses di komputer Anda. Statistik pemakaian hanya dikirim jika Anda sendiri mengaktifkan telemetri opsional.

Data yang diproses secara lokal

Berkas yang Anda buka, tabel basis data yang Anda tarik, halaman web yang Anda pindai, hasil perhitungan, dan berkas ekspor diproses pada komputer Anda. SheetEngine tidak mengunggah isi berkas, nama kolom, kueri, hasil perhitungan, maupun kredensial basis data kepada pengembang.

Telemetri opsional

Telemetri mati secara bawaan. Jika diaktifkan melalui Pengaturan, aplikasi mengirim sidik SHA-256 pengenal perangkat keras, versi aplikasi, versi dan arsitektur Windows, kapasitas RAM, akumulasi waktu pemakaian, serta waktu terakhir aktif. Nama pengguna dikirim sebagai Anonim; pengenal perangkat keras aslinya tidak dikirim.

Telemetri digunakan untuk mengetahui versi yang masih dipakai, mengukur kebutuhan perangkat, dan mendiagnosis masalah rilis. Telemetri dapat dimatikan kembali dari Pengaturan. Pengelola perangkat juga dapat memaksanya mati melalui variabel lingkungan SHEETENGINE_TELEMETRI=0.

Jejak audit, cache, dan diagnostik

Jejak audit dan cache disimpan di %LOCALAPPDATA%\SheetEngine dan tidak dikirim otomatis. Laporan diagnostik hanya dibuat ketika Anda memilih mengekspornya. Laporan tersebut menyaring jalur pengguna, alamat email, kata sandi, token, dan kunci API sebelum disimpan.

Kredensial basis data

Kata sandi yang Anda pilih untuk disimpan ditempatkan di Windows Credential Manager. Kata sandi tidak ditulis dalam bentuk terbaca ke berkas konfigurasi, jejak audit, atau laporan diagnostik.

Penjualan data dan iklan

Kami tidak menjual data pribadi dan tidak menggunakan jaringan iklan.

Akses, penghapusan, dan kontak

Privacy Policy

Effective September 26, 2026

SheetEngine Enterprise is a desktop application for processing tabular files and database sources. Files you open are processed on your computer. Usage statistics are sent only if you enable optional telemetry.

Locally processed data

Files you open, database tables you retrieve, web pages you scan, calculation results, and exported files are processed on your computer. SheetEngine does not upload file contents, column names, queries, calculation results, or database credentials to the developer.

Optional telemetry

Telemetry is off by default. If enabled in Settings, the app sends a SHA-256 fingerprint of a hardware identifier, app version, Windows version and architecture, installed RAM, accumulated usage time, and last-active time. The username field is always Anonymous; the original hardware identifier is never transmitted.

Telemetry is used to identify app versions still in use, understand device requirements, and diagnose release problems. You can turn it off in Settings. Device administrators can also force it off with SHEETENGINE_TELEMETRI=0.

Audit trail, cache, and diagnostics

The audit trail and cache are stored under %LOCALAPPDATA%\SheetEngine and are not transmitted automatically. A diagnostic report is created only when you choose to export one. User paths, email addresses, passwords, tokens, and API keys are redacted before the report is saved.

Database credentials

Passwords that you choose to save are stored in Windows Credential Manager. They are not written in readable form to configuration files, audit trails, or diagnostic reports.

Data sales and advertising

We do not sell personal data or use advertising networks.

Access, deletion, and contact

Send privacy questions and telemetry access or deletion requests to salmanir55@outlook.com. Additional verification may be requested to prevent deletion of another person's data.
